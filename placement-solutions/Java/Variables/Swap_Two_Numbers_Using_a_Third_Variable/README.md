## Problem Description

Given two integers A and B, swap their values using a third temporary variable and print the swapped values separated by a space.

## Explanation

Initial values: A = 10, B = 20. Storing A in temporary variable temp = 10, then A = B (A becomes 20), B = temp (B becomes 10). Output is 20 10.
